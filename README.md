# NearShelf

**Your agent asks nearby shops, so you don't have to.**

NearShelf is an entry for the [Open Agentic Web Challenge](https://cognizant-agenticweb.devpost.com/).

- **Each shop has its own agent** on its own website, and it answers from the shop's billing system.
- **A shopper has a personal agent** that runs in their browser. It asks those shop agents whether they have a medicine or a vehicle part, compares the answers, and holds the item for pickup.
- **No calls and no marketplace.** Shops don't learn who asked unless you hold an item.

The demo is set in **Neem Chowk**, a fictional neighbourhood. Every shop, brand and stock level in it is made up.

## Run it

Needs Node.js 22 or newer. There are no npm dependencies.

```shell
npm test                             # run every test
npm run dev                          # run the whole Neem Chowk area (Ctrl+C stops it)
node shop-kit/generate.mjs --all     # regenerate the five shop sites
npm run build:nearshelf              # rebuild the shopper agent's network file
```

`npm run dev` serves every site on its own host name and port, so each one is a separate origin, as it would be when hosted:

| Site | Address |
|---|---|
| NearShelf (the shopper's agent) | http://127.0.0.1:8080/ |
| Shanti Medical | http://localhost:8081/ (counter: `/counter.html`, dashboard: `/dashboard.html`) |
| Night Owl Pharmacy (24 hours) | http://[::1]:8082/ |
| Jeevan Chemist | http://localhost:8083/ |
| Bharat Auto Spares | http://localhost:8084/ |
| Speedline Moto Parts | http://[::1]:8085/ |
| Vayu Parts Catalogue | http://[::1]:8086/ |

Each shop keeps its demo stock in `.data/<shop>.json`. **Reset demo stock** on a shop's dashboard puts it back to the billing export.
