# Jeevan Chemist

Jeevan Chemist is a fictional Pharmacy in the Neem Chowk demo, and an open agentic website. Its own agent answers what is on the shelf right now, from the shop's live billing stock, and holds items for pickup.

This folder is generated by the NearShelf shop kit, `node shop-kit/generate.mjs jeevan_chemist`. Change the template (`shop-kit/template/`), the profile (`shop-kit/shops/jeevan_chemist.json`) or the billing export (`shop-kit/samples/jeevan_chemist.csv`), then generate again. Never edit this folder by hand.

## Run it

From the repository root, run `npm run dev`. It serves every Neem Chowk site, this shop included, with its stock API. To serve only this shop:

```shell
node tools/serve-shop.mjs sites/jeevan_chemist --shop jeevan_chemist --allow-reset
```

| Page | What it is |
|---|---|
| `index.html` | The shop's page: facts, a live stock search, holds, and "Ask Jeevan Chemist" |
| `counter.html` | The demo billing counter: add items with a typed quantity, change or remove lines, then bill them all at once. Each bill changes the stock the agent answers from |
| `dashboard.html` | Holds to set aside, marked Collected (billed) or Released (back on the shelf), missed demand (what people asked for that the shop didn't have), low stock, and **Update stock** from a new billing export (shown before it is saved) |

## The agent

The network URL is `jeevan_chemist` under the shop's origin. Its front agent is `jeevan_chemist_assistant`.

| Tool | Effect | On this page | When another site calls |
|---|---|---|---|
| `check_stock` | read | live bands from `/api/stock` | shared with every site (`"*"`) through the bridge |
| `get_shop_info` | read | facts, hours, partner links | shared with every site (`"*"`) |
| `request_hold` | write | the shop's hold form in a dialog | the shop's own window, for NearShelf and the other Neem Chowk shops only |

- **Stock** is shown as `in_stock`, `limited` (1 to 3 left) or `out_of_stock`, never exact counts.
- **Holds** take the visitor's name and phone in the shop's own form. Whoever asked gets back only the hold code and what is held.
- **Prescription medicines** can be held, and the pharmacist checks the prescription at the counter. Schedule X medicines are never held.
- **Partner shop.** If an item is out, the agent offers to ask the shop's partner, but only after the visitor agrees on a consent card.

## What goes where

- **The visitor's messages,** and the facts and stock the assistant reads, go to the AI provider the visitor chooses.
- **A shopper's name and phone** for a hold go only to this shop's stock API. The dashboard shows only the first name and the phone's last two digits.
- **The public files** (`agent-manifest.json`, `jeevan_chemist.network.json`, `links.json`, `agent-mcp.json`, `.well-known/`) are served with `Access-Control-Allow-Origin: *`. `_headers` sets the same headers on Netlify-style hosts.
